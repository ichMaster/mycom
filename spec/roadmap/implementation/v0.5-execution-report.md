## Detailed Results

### MC-032: Command-line widget + cd interception
**Status:** completed · **Commit:** 51b2f1c
**Validation:** [x] pytest · [x] ruff · [x] contracts · [x] acceptance
`mycom/console/cd.py` (`parse_cd`) and `mycom/widgets/command_line.py` (`CommandLine`). Printable
keys with no matching keymap action now route to the command line; `cd` applies directly to the
active panel, no subprocess. Found and fixed three real bugs during implementation: `Input`'s
`select_on_focus=True` racing same-tick character insertion; a keymap-bound key (e.g. `+`) also
bubbling to `on_key` and risking a double-fire; focus left stranded on the Input after submit,
silently swallowing the next panel key. 17 new tests.

### MC-033: Ring buffer + PTY runner core
**Status:** completed · **Commit:** 5ed8d5e
**Validation:** [x] pytest · [x] ruff · [x] contracts · [x] acceptance
`mycom/console/ring_buffer.py` (`RingBuffer`) and `mycom/console/pty_runner.py` (`run_in_pty`,
stdlib `pty.spawn` + a `master_read` tee). Found and fixed two real bugs via real subprocess
execution: the original `cd DIR && exec COMMAND` wrapping broke anything beyond a bare command
(exec doesn't interpret shell syntax); a PTY's line discipline leaves a stray `\r` on every line,
now normalized in `RingBuffer`. 16 new tests, all against real (non-mocked) subprocesses.

### MC-034: Wire Enter-to-execute: suspend/run/resume, exit code, panel refresh
**Status:** completed · **Commit:** 0d1842f
**Validation:** [x] pytest · [x] ruff · [x] contracts · [x] acceptance
`App.suspend()` + `run_in_pty` hands the terminal to a non-cd command; "Press any key" / exit code
via a small `_MessageScreen`; both panels refresh after. Found and fixed a real deadlock: an
`async`/`await`-based first draft blocked Textual's own message loop on a Future only a later
keypress could resolve (Textual runs one handler to full completion before the next). Fixed with
the callback form, matching every other multi-step dialog flow in the app. 8 new tests.

### MC-035: Ctrl+O toggle + cd-sync polish

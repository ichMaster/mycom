# MyCom

A modern, keyboard-driven dual-panel file manager for the terminal, inspired by FAR Commander.

## Features

- **Dual-panel layout** — two side-by-side directory panels
- **Keyboard-first** — all operations via hotkeys (F-keys)
- **Pluggable viewers/editors** — extend with custom plugins
- **Integrated terminal** — switch any panel to a full terminal
- **LLM chat** — context-aware Claude assistant in any panel

## Quick Start

```bash
# Install
uv sync

# Run
uv run mycom
```

## Project Status

MyCom is in early development (Phase 1 — Foundation).

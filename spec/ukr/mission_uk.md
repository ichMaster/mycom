# Місія — MyCom

> Українська копія [mission.md](../mission.md). Канонічна версія — англійська; у разі розбіжностей вона має пріоритет.

## Одним реченням

MyCom — клавіатуро-орієнтований двопанельний TUI файловий менеджер у дусі FAR Manager, написаний на Python поверх Textual, кросплатформний, із двома вбудованими диференціаторами, яких не має жоден ортодоксальний файловий менеджер: AI-палітрою команд і першокласною інтеграцією з Claude Code.

## Що ми будуємо

Вірний спадкоємець ортодоксального файлового менеджера: дві панелі, операції на F-клавішах, командний рядок під панелями, вбудовані переглядач і редактор, класичний синій вигляд FAR — усе, чого очікує м'язова пам'ять користувача FAR чи Midnight Commander, — і все це нативно на macOS та Linux (Windows — за залишковим принципом). Обсяг функціональності не вигаданий: він походить із систематичного сканування справжньої кодової бази FAR Manager ([far-spec/PYTHON_TUI_PRODUCT_SCOPE.md](../far-spec/PYTHON_TUI_PRODUCT_SCOPE.md)), перегрупованого й перепріоритезованого під реальність Python/POSIX.

Поверх цього перевіреного ядра — два нові модулі, справжня причина існування продукту:

1. **LLM-інтеграція** — AI-палітра команд (природна мова → shell-команда, ніколи не виконується автоматично), далі контекстний чат-сайдбар, пояснення/підсумовування та розумне виділення. Прямий Anthropic API, стрімінг, структуровані відповіді.
2. **Інтеграція з Claude Code** — від «відкрити Claude Code у цій теці» (одне натискання, панелі оновлюються після виходу агента) до headless-запуску задач і повного вбудовування через Agent SDK із TUI-діалогами дозволів.

Продукт на 100 % функціональний без API-ключа та мережі. AI — це шар, а не залежність.

## Для кого

- Розробники та системні адміністратори, які живуть у терміналі.
- Користувачі FAR Manager / Midnight Commander, які хочуть ту саму м'язову пам'ять на macOS і Linux.
- Досвідчені користувачі, які хочуть файли, shell і AI-агента в одному робочому просторі замість трьох вікон.

## Принципи

- **Відчувається як Far.** Клавіші за замовчуванням віддзеркалюють FAR (`F5` копіювати, `Ins` виділити, `Ctrl+U` обмін панелей); тема за замовчуванням — точна палітра FAR з `colormix.cpp`/`palette.cpp`; панель F-клавіш, діалоги та підвали панелей повторюють розкладку FAR. Впізнаваність — це функціональність.
- **Клавіатура насамперед.** Кожна функція доступна без миші; миша — опція всюди.
- **Жодної втрати даних, ніколи.** Вихідні файли недоторканні, доки операція повністю не завершиться; скасування завжди безпечне; конфлікти завжди запитують.
- **UI ніколи не замерзає.** Один асинхронний цикл подій володіє всіма змінами UI (правило єдиного записувача); все довше за 100 мс виконується як worker із видимим прогресом і досяжною кнопкою Cancel.
- **Офлайн-деградація.** Кожна точка входу в AI — опціональна. Немає ключа → діалог налаштування, а не traceback. Жодного мережевого трафіку, доки AI-функцію явно не викликано.
- **Підтвердження перед запуском.** Згенерована shell-команда ніколи не виконується без явної дії користувача; небезпечні патерни позначаються червоним ще до того, як Run стане можливим. Те саме правило керує вбудованим агентом: використання інструментів Claude Code проходить через TUI-діалоги дозволів.
- **Дані, а не хардкод.** Маски, підсвічування, асоціації, меню, клавіатурні мапи й кольори живуть у даних (конфіг + файли теми), а не в коді — урок довголіття FAR.
- **Будувати чи вбудовувати.** Редактор і переглядач FAR — по ~20k рядків кожен; ми їх не переписуємо. Планку задають `TextArea` з Textual плюс запасний вихід `$EDITOR`, а зекономлені зусилля йдуть в AI-модулі.
- **Ізоляція платформи.** Один пакет `platform/` — єдине місце для OS-залежного коду; архітектурний урок самого FAR.
- **Ядро перед оздобленням.** SQLite-персистентність, рушій масок і діалоговий набір — фундаменти, які використовують багато функцій; вони будуються один раз, рано, і перевикористовуються всюди.

## Не-цілі

- **Не порт FAR.** Жодних C++-нутрощів і реліктів Windows-епохи: перегляд SMB-мережі, скринсейвер /грабер екрана, безпечне стирання, сумісність з OEM-плагінами, доступ до реєстру, NTFS-потоки — все явно поза межами.
- **Не IDE і не термінальний мультиплексор.** Консольна поверхня запускає команди та повноекранні програми; решту робить tmux.
- **Поки що без маркетплейсу плагінів.** Публічний API плагінів — тема фази зрілості (v2+); v0–v1 постачають лише вбудовані можливості (архіви через stdlib, не через плагіни).
- **Без першокласної підтримки Windows у v0–v1.** POSIX (macOS + Linux) — першокласний; Windows — за залишковим принципом через conpty, і йому дозволено відставати.
- **Не універсальний AI-чат.** AI-функції існують, щоб маніпулювати файлами й запускати команди в контексті, а не щоб замінити чат-клієнт.

## Глосарій

- **Ортодоксальний файловий менеджер** — школа двопанельних клавіатурних файлових менеджерів, започаткована Norton Commander і доведена до досконалості FAR.
- **Активна / пасивна панель** — панель із курсором та протилежна їй; файлові операції за замовчуванням націлені на теку пасивної панелі.
- **Виділення** — явно позначений набір файлів (`Ins`, виділення за маскою); операції діють на виділення, коли воно непорожнє, інакше — на файл під курсором.
- **Файлові маски** — мова шаблонів FAR (`*.py;*.md|*test*`), яку перевикористовують виділення, підсвічування, фільтри та пошук файлів (v1).
- **Панель F-клавіш (key bar)** — нижній рядок із 10 слотів F-клавіш із контекстними підписами, що генеруються з клавіатурної мапи, тож підписи ніколи не розходяться з прив'язками.
- **Консольна поверхня** — повноекранний вивід, у якому виконується команда; `Ctrl+O` повертає останній вивід після повернення до панелей.
- **cd-sync** — інваріант: робоча тека командного рядка завжди дорівнює теці активної панелі, в обидва боки.
- **Діалоговий набір (dialog kit)** — єдиний повторно використовуваний модальний рушій (рамка, заголовок, поля, кнопки, гарячі літери), на якому побудовано кожен діалог; нуль ad-hoc модального коду.
- **Тема «Far classic»** — палітра за замовчуванням, знята з вихідного коду FAR: сині панелі `#000080`, блакитні рамки `#00ffff`, сірі діалоги `#c0c0c0`, жовте виділення `#ffff00`.
- **База стану (State DB)** — єдина база SQLite (WAL) зі станом панелей, історіями та позиціями; окрема від авторського TOML-файла налаштувань.
- **Шов `LLMClient`** — тонкий інтерфейс між ядром і Anthropic SDK; весь AI проходить крізь нього, тому тести мокають шов і жоден платний виклик ніколи не виконується в CI.
- **AI-палітра команд** — `Ctrl+Space`: намір природною мовою → запропонована shell-команда + пояснення + рівень небезпеки, з діями Run / Edit / Copy / Cancel.
- **Розумне виділення** — природна мова → предикат виділення («виділи всі логи, старші за тиждень») через структуровані відповіді (v1).
- **Чат-сайдбар** — контекстна панель чату з Claude, яка знає поточну теку, виділення та переглянутий файл (v1).
- **Claude Code** — CLI-агент кодування від Anthropic (`claude`); MyCom запускає його в активній теці (v0), керує ним headless (`claude -p`, v1) і вбудовує через Agent SDK (v1).
- **Діалог дозволу** — TUI-діалог, що показує запит вбудованого агента на використання інструмента (редагування файлу, запуск команди) для явного схвалення користувачем.

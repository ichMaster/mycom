MyCom — Release History
=======================

Version 0.4.0 (2026-08-03)
---------------------------
- File operations: Copy/Move (F5/F6) — same-filesystem move is an instant rename(), cross-device
  is a verified copy-then-delete; Mkdir (F7) creates a nested a/b/c path in one step; Delete (F8)
  with a confirmation ladder (routine + non-empty-directory + per-read-only-file) and the
  confirm_delete config option now wired; Rename (Shift+F6) in place with the name's stem
  pre-selected
- Every operation runs on a background worker thread with live progress, bytes/files/speed/ETA,
  and a real Cancel button; a six-choice conflict dialog (Overwrite/Skip/Rename/Overwrite All/
  Skip All/Cancel) on any name collision, with "All" answers scoped to one operation
- Code review fix: an unexpected OSError (permission denied, disk full, a vanished source) during
  any file operation now shows a clean error dialog instead of crashing the app

Version 0.3.0 (2026-08-03)
---------------------------
- Selection model: Ins/Space toggle, mask select/deselect/invert, yellow highlight, live footer
  count + size
- Ctrl+H global hidden-files toggle
- SQLite (WAL) state persistence for panel path/sort/view and hidden toggle, with vanished-path
  fallback

Version 0.2.0 (2026-08-02)
---------------------------
- v0.2 Dialog kit, Far theme, key bar: single-source theme file (256-color safe)
- DialogKit reusable modal engine (Tab/arrow focus, hotkeys, Enter/Esc, stacking) with all four
  dialogs rebuilt on it
- F1-F10 key bar generated from the keymap registry
- Completed panel footer

Version 0.1.1 (2026-08-02)
---------------------------
- v0.1 Panel core retrofit: data-driven keymap registry, config-wired panels, structured logging
- Ctrl+U panel swap, cursor-restore-on-up, EACCES/vanished-directory error dialog, resizable panels
- Brief/Full/Wide view modes
- FAR sort keys (Ctrl+F3-F6) with header direction glyph

Version 0.1.0 (2026-05-08)
---------------------------
- MC-001: Project scaffold and package structure — uv-managed Python project with hatchling build
- MC-002: Configuration and key bindings — TOML config loader with frozen dataclasses, key binding registry
- MC-003: Core widgets — FileList DataTable, StatusBar, PathBar, AppHeader, modal dialogs
- MC-004: Filesystem utilities — FileEntry dataclass, directory listing, format helpers
- MC-005: Panel system and file browser panel — BasePanel abstract class, FileBrowserPanel with sort/filter
- MC-006: Application shell and dual-panel layout — Dual-panel Textual app with Tab switching, F-key bindings
- MC-007: File navigation, quick filter, and sorting — Enter/Backspace navigation, real-time filter, multi-field sort
- MC-008: Documentation site and API reference — MkDocs Material with auto-generated API docs
